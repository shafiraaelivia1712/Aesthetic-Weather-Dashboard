## 🌟 Tentang Proyek

**Aesthetic-Weather-Dashboard** adalah aplikasi web mini yang dirancang untuk menampilkan informasi cuaca secara real-time dengan sentuhan desain visual yang estetis. Proyek ini memadukan kesederhanaan antarmuka pengguna dengan fungsi JavaScript dinamis.

---

## ✨ Fitur Utama

* **Informasi Cuaca Dinamis** : Menampilkan suhu, kondisi cuaca, dan parameter penting lainnya.
* **Desain Estetik** : Antarmuka visual yang memanjakan mata dengan tema modern.
* **Struktur Ringan** : Dibangun tanpa *framework* yang berat, sehingga sangat cepat diakses.
